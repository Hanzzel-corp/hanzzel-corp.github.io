NCT Dossiers: tres resúmenes ejecutivos para estudiar el proyecto

NCT Dossiers reúne tres documentos PDF breves que sintetizan obras del proyecto NCT: un dossier técnico de La Quinta Fuerza Universal, una síntesis de proceso de NCT — La gestación de una idea y un dossier de diseño de Curvibits Cuánticos. La colección está pensada como puerta de entrada y orientación documental; los libros completos no están publicados en este repositorio.

Repositorio público · README y descripción de los documentos · Condiciones de uso y copyright

Alcance de esta ficha: los tres archivos PDF están presentes en el repositorio. Las descripciones de su contenido que siguen resumen lo que el README declara; esta ficha no afirma una auditoría independiente de cada resultado numérico ni sustituye la lectura de los documentos originales.

2. Cómo se relacionan los tres dossiers

  • La Quinta Fuerza Universal: concentra la descripción técnica de un experimento computacional y sus criterios de evaluación/falsabilidad.
  • NCT — La gestación de una idea: aporta la dimensión histórica y de inventario, diferenciando sistemas reproducibles, funcionales, prototipos y elementos conceptuales o de visión, según la clasificación resumida en el README.
  • Curvibits Cuánticos: documenta una línea de diseño de unidad de cómputo cuántico-inspirada y el estado declarado de sus componentes.

Leídos en conjunto, los dossiers ofrecen tres perspectivas complementarias: experimento, trayectoria de desarrollo y diseño de arquitectura. No deben interpretarse como tres demostraciones independientes de una teoría unificada.

3. Resultados y niveles de afirmación

El README del repositorio atribuye al dossier de La Quinta Fuerza Universal resultados estadísticos concretos: p < 0.01 en 30/30 corridas grouped block y p ≤ 0.017 en 24/24 corridas leave-one-cluster-out. Esos valores se presentan aquí como resultados reportados por la documentación del proyecto, no como resultados reanalizados en esta ficha. Para evaluarlos hacen falta el protocolo completo, los datos, el código, la definición de hipótesis, los controles y la reproducción independiente.

La presencia de condiciones de falsabilidad y niveles de afirmación es una característica documental relevante: permite separar implementación, robustez y programa de investigación. La existencia de esos criterios no equivale por sí sola a que todas las afirmaciones hayan sido validadas externamente.

4. Relación con código y experimentos públicos

El README identifica NCT Depth Motif como repositorio abierto del experimento RGB-D asociado a la línea técnica de La Quinta Fuerza Universal. La ficha técnica correspondiente describe el método computacional, sus pruebas y sus límites. Los otros sistemas mencionados en los dossiers deben enlazarse a sus repositorios concretos y a versiones identificables antes de atribuirles resultados específicos.

English version · Document collection brief

NCT Dossiers: three executive summaries for exploring the project

NCT Dossiers contains three short PDF documents summarizing works in the NCT project: a technical dossier for La Quinta Fuerza Universal, a development-history dossier for NCT — La gestación de una idea, and a design dossier for Curvibits Cuánticos. The full books are not published in this repository.

Included documents

  • La_Quinta_Fuerza_Dossier.pdf: the README describes an NYU Depth V2 experiment, reported statistical results, formal connections to prior literature and four claim levels with falsifiability conditions.
  • NCT_La_gestacion_Dossier.pdf: a project timeline from April 2024 to May 2026, a status table for fourteen systems, and distinctions between claims, limitations and falsifiability.
  • CQ_Dossier.pdf: an operational CQ description using α, β, γ and ε, a PennyLane/default.qubit configuration, a status table for fourteen components and claim levels.

How the documents relate

The three dossiers provide complementary perspectives: computational experiment, development history and system design. They should not be read as three independent proofs of a unified theory.

Reported results and evidence status

The repository README reports p < 0.01 in 30/30 grouped-block runs and p ≤ 0.017 in 24/24 leave-one-cluster-out runs for the experiment described in the technical dossier. These are reported project results, not independently reanalyzed findings on this page. Evaluation requires the full protocol, data, code, hypotheses, controls and independent reproduction.

Code relationship

The README links NCT Depth Motif as the public code repository associated with the RGB-D experiment. Its technical page describes the computational method and its limitations.

Access and copyright

The repository publishes executive summaries, not the complete books. Its copyright notice allows personal reading, attributed partial quotation and sharing the public repository link, while restricting reproduction, distribution, translation, derivative works and dataset use without written permission. Open-source code licensing in separate repositories does not automatically license these texts.

Interpretation limits

  • The repository confirms the presence of three PDF dossiers and a README describing them.
  • Statistical values remain project-reported until the complete protocol is inspected and reproduced.
  • The system-status tables are project classifications, not external maturity certifications.
  • The dossiers do not replace the full books, source code or reproduction materials.
