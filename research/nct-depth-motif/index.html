NCT Depth Motif: validación de motivos discretos en mapas de profundidad

NCT Depth Motif es un experimento computacional que evalúa una representación simbólica discreta de descriptores locales de profundidad sobre NYU Depth V2. Cada píxel se representa mediante un motivo de tres componentes —gradiente horizontal, gradiente vertical y laplaciano local— cuantizadas en cuatro estados: {+, −, 0, ~}.

Estado: reporte técnico exploratorio, no revisado por pares. El repositorio informa resultados estadísticamente significativos frente a permutaciones aleatorias, pero de magnitud práctica modesta. No se ha presentado este experimento como un detector superior al estado del arte.

1. Pregunta experimental

La pregunta es si una tabla de pesos aprendida para motivos discretos contiene información útil para estimar discontinuidades geométricas en mapas de profundidad, y si su rendimiento en un conjunto de prueba independiente supera al de permutaciones aleatorias de esos mismos pesos.

La hipótesis nula publicada sostiene que los pesos aprendidos no son distinguibles de pesos permutados al azar en las métricas evaluadas. La alternativa sostiene que la asociación motivo → target ofrece una mejora estadísticamente detectable.

2. Representación y método

  1. Entrada: mapas de profundidad NYU Depth V2 en PNG de 16 bits, convertidos a metros.
  2. Descriptores locales: cálculo de Sx (gradiente horizontal), Sy (gradiente vertical) y Sz (laplaciano local).
  3. Cuantización: cada componente se asigna a uno de cuatro estados: +, −, 0 o ~ (transición).
  4. Motivos: la tupla ordenada (Sx,Sy,Sz) genera 4³ = 64 combinaciones posibles.
  5. Entrenamiento: se estima el lift medio de cada motivo respecto del target, con shrinkage para regularizar motivos poco frecuentes; el resultado es una tabla de 64 pesos.
  6. Evaluación: se aplica una corrección residual con gate de ambigüedad y se compara con el delta clásico, pesos permutados al azar, variantes discretas y una tabla fija previa.

La forma publicada de la corrección es:

score = delta + alpha * ambiguity_gate * weight_table[motif]

El gate triangular reduce la corrección cuando el delta clásico ya discrimina con claridad. La documentación del proyecto especifica además la definición del target, los umbrales y los hiperparámetros.

4. Qué significan —y qué no significan— los resultados

Los p-values informados indican que, bajo el procedimiento de permutación descrito, los modelos principales superaron consistentemente a los pesos permutados. La mejora absoluta es pequeña: aproximadamente +0.004 en AUC y +0.005 en F1 frente al baseline aleatorio para el modelo principal. El modelo binario, que conserva principalmente el signo de los pesos, obtiene resultados competitivos o superiores en algunas métricas.

La conclusión acotada es que, en el dominio y las particiones descritas, la representación de motivos contiene una señal estadística detectable frente a esos baselines aleatorios. Esto no demuestra que sea la cuantización óptima, que generalice a otros datasets ni que supere a detectores clásicos.

5. Limitaciones explícitas

  • Efecto modesto: ΔF1 es aproximadamente +0.005 frente al baseline aleatorio.
  • Sin benchmark clásico: no hay comparación directa en el mismo benchmark contra Canny, Sobel o HED.
  • Clusters no semánticos: el leave-one-cluster-out utiliza ocho clusters k-means sobre RGB, no las etiquetas semánticas oficiales de NYU; el README marca la validación con scene_types.txt como pendiente.
  • Un dataset: los resultados publicados corresponden a NYU Depth V2; no se informa validación cross-dataset en ScanNet, KITTI o SUN RGB-D.
  • Target derivado del depth map: el target de ruptura se deriva del propio mapa de profundidad y no de anotaciones manuales de bordes.
  • Estado académico: reporte técnico exploratorio, no revisado por pares.

6. Reproducción

El dataset NYU Depth V2 no está incluido en el repositorio. Debe obtenerse desde su fuente oficial y ubicarse según la estructura descrita por el proyecto. El README especifica Python 3.9+, NumPy, Pillow y SciPy; PyTorch con CUDA es opcional para acelerar el cálculo.

git clone https://github.com/Hanzzel-corp/nct-depth-motif.git
cd nct-depth-motif
pip install -r requirements.txt

# Ejemplo grouped split: parámetros publicados en el README
python3 src/motif_survival_grouped.py \
  --depth ./dataset/depth \
  --target combined \
  --alpha 0.02,0.03,0.04 \
  --seeds 11,22,33,44,55,66,77,88,99,111 \
  --random-baselines 256 \
  --device cuda \
  --split-mode grouped \
  --group-strategy numeric_block \
  --group-size 50 \
  --depth-scale 1000 \
  --fx 518.8579 --fy 519.4696 --cx 325.5824 --cy 253.7362

Para la evaluación leave-one-cluster-out, consultar el comando completo en README.md y los scripts de ejemplo. La disponibilidad de GPU, memoria y dataset afecta el tiempo de ejecución. Esta ficha no afirma que se haya vuelto a ejecutar el experimento durante su publicación.

8. Contexto NCT

El proyecto se originó en el marco simbólico NCT desarrollado por su autor. Para este experimento específico, lo que se evalúa es una representación discreta concreta y su procedimiento de validación. El propio README contextualiza sus equivalencias técnicas —producto cartesiano finito, cuantización vectorial y clasificación mediante tabla de consulta— y aclara que el resultado validado aquí no debe presentarse como una nueva matemática demostrada.

English version · Technical research brief

NCT Depth Motif: experimental validation of discrete motifs on depth maps

NCT Depth Motif evaluates a discrete symbolic representation of local depth descriptors on NYU Depth V2. Each pixel is represented by a three-component motif — horizontal gradient, vertical gradient and local Laplacian — quantized into four states: {+, −, 0, ~}, yielding 64 possible motifs.

Research question and method

The experiment asks whether weights learned for discrete motifs carry useful information for estimating geometric discontinuities on depth maps, and whether they outperform random permutations of those weights on independent test data. The pipeline computes Sx, Sy and Sz, discretizes each component into four states, estimates a 64-entry weight table with shrinkage, and applies a gated residual correction:

score = delta + alpha * ambiguity_gate * weight_table[motif]

Reported results

The repository reports a grouped numeric block split with 30 runs (3 alpha values × 10 seeds), 654 NYU Depth V2 test frames and 256 random baselines. For motif_survival, reported p-values are 0.0039 (F1), 0.0079 (AUC) and 0.0039 (Spearman), with ΔAUC +0.0038 and ΔF1 +0.0052 versus random. The binary variant reports p-values 0.0039, 0.0039 and 0.0039, with ΔAUC +0.0070 and ΔF1 +0.0054.

A leave-one-cluster-out experiment reports 24 runs across eight automatically generated RGB clusters. The main and binary models report p-values below 0.017 for the listed metrics. These are repository-reported results, not an independent reproduction performed by this page.

Interpretation and limitations

The reported permutation tests show a consistent statistical signal against the specified random baselines, but the absolute effect is small. The project has not been directly compared with Canny, Sobel or HED in the same benchmark; uses only NYU Depth V2; uses RGB k-means clusters rather than official semantic scene labels; and derives its rupture target from the depth map itself rather than manually annotated edges. The report is exploratory and not peer-reviewed. It does not establish state-of-the-art performance, cross-dataset generalization or a proven new mathematical theory.

Reproduction

The dataset is not included. Obtain NYU Depth V2 from its official source, follow the setup and commands in the repository README, and inspect the source scripts, result files and technical documents.
