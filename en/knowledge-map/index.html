How the map evolves

  1. Assign each project a stable identifier and canonical URL.
  2. Tie claims to a README, source code, release, dataset, protocol, paper or DOI.
  3. Classify relationships such as implements, evaluates, reproduces, documents, depends on, publishes or commercial application.
  4. Record versions and dates to distinguish current state from historical results.
  5. Create NCT concept pages and link them to implementations that actually use those concepts.
