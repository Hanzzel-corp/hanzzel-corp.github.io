Cómo evoluciona el mapa

  1. Asignar identificador estable y URL canónica a cada proyecto.
  2. Vincular afirmaciones a README, código, release, dataset, protocolo, paper o DOI.
  3. Clasificar relaciones: implementa, evalúa, reproduce, documenta, depende de, publica o aplicación comercial.
  4. Registrar versiones y fechas para separar estado actual de resultados históricos.
  5. Crear páginas de conceptos NCT y conectarlas con implementaciones que realmente los utilicen.
